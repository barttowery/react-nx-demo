# Introduction

The Shared Component library contains common components and is used by the frontend web applicatoin.
This shared library sets many of the design patterns that should be used across the solution.

## Basic Design Principles

The following libraries and concepts have been used to create the Apollo frontend:

- [Tailwind v4](https://tailwindcss.com/) - used for styling
- [ShadCn](https://ui.shadcn.com/) - many of the shared components use code from ShadCn
- [Radix UI](https://www.radix-ui.com/) - ShadCn is based on Radix UI

Basic coloring, typography and customizations to Tailwind include the following:

- [Colors](?path=/docs/foundations-colors--docs)
- [Typography/Fonts](?path=/docs/foundations-typography--docs)
- [Round Corners](?path=/docs/foundations-round-corners--docs)
