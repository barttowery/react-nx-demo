# Typography

<strong>Geist</strong> is the default font for the web application. The base font size is 16px;

## Header Styles

The header style for a page uses Geist and the text-2xl size (24px). The full list of styles are:
`text-2xl py-3 px-6 font-medium bg-color-card text-color-primary-text`
